「Project Loop Room」は、空間そのものを使った3D脱出ゲームです。
**「理解＝攻略」**をコンセプトとし、プレイヤーが空間の法則やギミックに“気づいた瞬間”を楽しむゲームデザインとなっています。

---

## ✨ 最新のアップデート: プレミアムUI
本作は、シンプルながらも高級感のあるモダンなUIデザインを採用しています。
- **豪華なタイトル画面**: スライドイン演出、角丸ボタン、美しいタイポグラフィによる没入感のある入り口。
- **インタラクティブなボタン**: 全てのボタンに滑らかなホバーアニメーション（拡大・明度調整）を搭載。
- **洗練されたガシャ画面**: 劇的な「煙（ホワイトアウト）」演出と、オーバーラップする重厚なサウンドによるアイテム獲得体験。
- **統一されたシステムUI**: ポーズメニューや設定画面に至るまで、黒を基調とした枠線付き角丸パネルで統一されたルック＆フィール。

## 🗝️ 各部屋の攻略方法（ネタバレ注意）

> 各部屋のギミックと解法の一覧です。プレイ体験を損なう可能性があるため、閲覧にはご注意ください。

| 部屋 | 目的 | 攻略のヒント・手順 |
| :--- | :--- | :--- |
| **① 導入ルーム**<br>*(チュートリアル)* | 基本操作の理解と目的の確認 | 部屋の中にある机から**「鍵」**を見つけ出し、奥のドアを開けるとクリア。<br>*(※時計の時間のズレは後のギミックの伏線)* |
| **② ループ廊下** | 空間の異常（ループ）に気づき、<br>変化を起こして脱出する | <ul><li>**1周目:** 廊下にある「箱」などの配置に違和感がないか確認する。</li><li>**2周目:** 「箱」の他に出現している「メモ（ヒント）」を調べる。</li><li>**3周目以降:** メモのヒントをもとに特定の行動を起こすことでループから外れ、**「扉」が開く**。</li></ul> |
| **③ 回転ルーム**<br>*(重力操作)* | 部屋の構造を変化させて<br>足場を作り出す | 中央付近の**「回転装置」**を起動して部屋を90度回転させる。<br>壁が床になるなど重力の方向が変わる性質を利用し、通常では届かなかったスイッチを押してドアを開く。 |
| **④ 視点トリック部屋** | カメラの視点（錯覚）を利用して<br>隠された道を開く | バラバラに配置されたオブジェクト（A、B、C）を特定の**「視点（カメラの角度・立ち位置）」**から覗き込む。<br>視点が合わさって一つの形に見えた瞬間、ロックが解除されて道が開く。 |
| **⑤ 分身ギミック室** | 過去の自分と協力して<br>2つのスイッチを同時に押す | <ol><li>**「記録装置」**を起動し、スイッチAの前に移動して待機する行動を記録する。</li><li>記録を**「再生」**し、自分の過去の行動を行う「分身」を出現させる。</li><li>分身がスイッチAに乗るタイミングに合わせて、自分はスイッチBに乗る（同時押し成功）。</li></ol> |
| **⑥ 最終統合ルーム** | これまでの全ギミックを<br>複合させてクリアする | <ol><li>**分身セット:** 「記録装置」を使い、自分の動き（回転装置の起動など）を記録させる。</li><li>**回転:** 分身（または自分）の操作で部屋を回転させ、地形を変化させる。</li><li>**視点合わせ:** 回転後の地形で、特定の立ち位置から「視点トリック」の形を合わせる。</li><li>**同時押し:** 視点が合った状態で出現するスイッチを、分身とタイミングを合わせて**「同時押し」**する。これを突破すれば脱出成功！</li></ol> |

## 🎮 コンセプト

- **空間そのものを使った3D脱出**: 単なるアイテム探しではなく、部屋の構造や法則を解き明かします。
- **「理解＝攻略」の構造**: テキストで過剰に説明せず、ギミックを通してプレイヤー自身に気づかせます。
- **プレミアムな操作感**: Tweenアニメーションを活用した心地よいUIレスポンス。

## 🗺️ 全体フロー（進行構造）

1. **Title Screen**: 旅の始まり。設定やガシャへのアクセス。
2. **Room 1-6**: 各部屋を攻略。
3. **End Credits**: 余韻を楽しむエンドロール。特別なクリア報酬（ガシャチケット等）の示唆。
4. **Gasha Screen**: 獲得した報酬で特別なアイテムやレア画像をコレクション。

## 💻 開発環境と仕様

- **エンジン**: Godot Engine (v4.6.2-stable_mono_win64)
- **解像度**: 1280 x 720 (720p) / スケーリング対応
- **物理エンジン**: Jolt Physics
- **メイン言語**: C# / GDScript
- **メインシーン**: `res://Scenes/UI/TitleScreen.tscn`

## 🧱 コアシステム設計

- **GameManager (Autoload)**: ループ回数、進行状態、オーディオ（BGM管理）、シーン遷移を統合管理。
- **Gasha System**: 画像・音声のオーバーラップ再生、ホワイトアウト演出を伴うガチャシークエンス。
- **UI System**: `StyleBoxFlat` を活用した動的なデザインシステムと、全画面共通のホバーアニメーション。

## 💡 演出・オーディオ設計

- **UI**: 縁取りと影を効かせたテキストにより、いかなる背景でも視認性を確保。
- **Tween演出**: `create_tween()` をフル活用し、ノードの移動、拡大、透明度変化を滑らかに表現。
- **オーディオ**: `AudioStreamPlayer` を複数使い、ガシャ演出時などの「音の重なり」を丁寧に実装。
